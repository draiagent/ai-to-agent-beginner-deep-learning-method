# 方法與 VAD／VAC
三問：核心觀念與關係是什麼？不同做法的證據與適用條件是什麼？能否用逐題提問驗證理解？

六步依序為確認起點、建立地圖、比較觀點、逐題追問、補強盲點、遷移驗收。沒有足夠資料時補來源；沒有明確爭議時比較誤解與適用情境，不硬湊專家共識。

VAD：將目標、來源、流程及答錯後回到資料的迴圈畫清楚。
VAC：保存知識、任務與驗收規格。Skill 是一句話入口；圖卡是可視化載體，兩者須一致。

任務規格：輸入教材與目標；工具按需提供資料讀取、搜尋、檔案保存；輸出地圖、問題、回饋與進度卡；驗收須依真實作答。AI 提問後等待，學員作答後才檢查，提示後再換題獨立驗證。

每次保存來源位置、作答證據、修正原因與下一題。不宣稱沒有保存過的內容可跨對話自動接續。
