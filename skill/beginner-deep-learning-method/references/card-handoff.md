# VAD／VAC 與圖卡轉換規格

方法識別：beginner-deep-learning-method；方法版本：1.0。
以 SKILL.md 的六步流程為執行依據。修改流程後同步檢查各種圖卡，不讓簡化文案改變原意。

## VAD：讓方法被看見
呈現學員痛點、學習目標、輸入來源、六步流程，以及「回答 → 檢查 → 補強 → 再驗證」的迴圈。明確區分 Agent 與學員責任，標示資料不足、提示後完成及獨立完成的分支。

## 技能圖卡：如何召喚與使用
準備內容：名稱、一句話用途、適用對象、啟動語、輸入、六步概要、成果與驗收。
啟動語：啟動深度學習模式，幫我學這份資料。
任務型 VAC 另列每步輸入、操作、輸出、工具需求及驗收；不綁定單一產品，依可用工具執行。

## 知識圖卡：為什麼這樣學
按一張一重點準備：
1. 建立地圖：先理解觀念關係，再進入細節。
2. 比較觀點：判斷證據與適用條件，不為爭論而爭論。
3. 主動作答：先自己回答，再接受回饋。
4. 補強盲點：說出錯誤原因，回到資料修正。
5. 遷移驗收：換個案例仍能獨立應用，才有理解證據。
6. 資產沉澱：保留來源、方法、進度與實例，支援接續與重用。
實際張數依使用者範圍與內容密度決定，以上是內容模組而非已批准的頁數。
每張包含核心觀念、白話說明、例子、常見誤解與一個自我檢查問題。不得將教育設計原則誇大為未經引用的研究結論。

## 生成前與驗收
先完成可校對文稿，再依使用者指定風格製圖；目前規格本身不代表已生成圖卡。圖片優先 PNG，文字規格使用 Markdown。依要求放入真實公司 Logo、頁碼、署名，不編造 Logo，不自行加版本標籤在畫面上。
檢查繁體中文、來源、步驟名稱與順序，以及圖卡是否離開對話也能理解。確認簡單召喚入口仍然保留。
